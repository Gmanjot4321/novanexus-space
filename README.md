# NovaNexus 🌌

An interactive, space-educational web application built with React, Vite, Supabase, and Three.js. NovaNexus lets users explore 3D celestial bodies, track real-time near-earth objects (NEOs), and dive into an expansive astronomical knowledge base.

## Live Demo
🌐 **Explore NovaNexus:** [https://novanexus-space.vercel.app](https://novanexus-space.vercel.app)

## Tech Stack
* **Frontend:** React, TypeScript, Tailwind CSS, Three.js / React Three Fiber
* **Backend & Database:** Supabase (PostgreSQL)
* **APIs & Data:** NASA API integration
* **Hosting & Deployment:** Vercel
